# 🎵 visual-

A beautiful, animated lyric visualizer for the line:

> "I wanna hold you, just for a while, and die with a smile."

This project displays a glowing text animation with gradient backgrounds, floating hearts, and background music to create a visually engaging experience.

---

## 🔥 Features

- 🎨 Animated gradient background
- 💖 Floating heart emojis
- 🌟 Glowing, centered lyrics
- 🎧 Audio playback support
